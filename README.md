# eBook — Audiobook

此项目是将 eBook 与音频资料进行整合，方便英语学习。

## 项目目标
- 汇集电子书与对应的音频资源，按章节/段落对齐，便于听读结合学习。
- 提供便捷的目录、检索与播放接口，支持个人学习与课堂使用。
- 支持常见音频与文本格式（MP3、M4A、EPUB、PDF 等）。

## 快速开始
1. 克隆仓库：
   git clone https://github.com/guolianzhi28-cmd/eBook.git
2. 在项目目录中创建并激活虚拟环境，安装依赖（后续会添加 requirements.txt）：
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
